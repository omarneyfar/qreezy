# Qreezy Project Documentation

Welcome to the official technical documentation for **Qreezy**, a modern marketing website built for a premium QR-based solution provider. This document outlines the architecture, design system, and technical implementation details of the project.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Runtime**: [React 19](https://react.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: 
  - **Global**: Vanilla CSS with Design Tokens (`src/app/globals.css`).
  - **Component Level**: `styled-jsx` for encapsulated, scoped CSS and responsive logic.
- **Language**: TypeScript (Strongly typed configuration and props).

## 🎨 Design System

Qreezy utilizes a premium "SaaS aesthetic" characterized by clean layouts, soft shadows, and vibrant accent colors.

### 1. Colors (CSS Variables)
Defined in `src/app/globals.css`:
- **Primary**: `#EF6F60` (Coral/Red) — Used for CTAs and branding.
- **Background**: `#FFFFFF` — Primary background color.
- **Secondary Text**: `#4B5563` — Used for descriptions and subtitles.
- **Premium Shadow**: `0 25px 50px -12px rgba(239, 111, 96, 0.15)` — Soft, themed shadow for elevation.

### 2. Components
- **Section**: Wrapper with responsive padding handles all vertical spacing.
- **SectionHeader**: Centralized title management with optional icon placement **above** the title.
- **Button**: Advanced `styled-jsx` component supporting `primary`, `secondary`, and `outline` variants with hover micro-interactions.
- **FeatureCard**: Standardized card for displaying benefits with Lucide icons.

### 3. Glassmorphism
The project includes `.glass` and `.glass-dark` utilities for background blur effects, primarily used in the fixed **Header** on scroll.

## 🛠️ Key Implementation Details

### Responsive Strategy
We use a **Mobile-First** approach combined with `styled-jsx` media queries for precise control:
- **Desktop**: 2+ column layouts for grids and hero sections.
- **Tablet/Mobile Transition**: The navigation switches to a mobile hamburger menu at **992px**, ensuring a smooth experience for larger tablets.
- **Mobile (< 768px)**: Single column layouts, stacked elements.
- **Logo Resizing**: The logo in the Hero section is controlled via props in the `Image` component, with CSS constraints removed to allow for dynamic scaling.

### Animations
- **Floating Hero**: An `@keyframes float` animation is applied to the main logo to create a dynamic, premium feel.
- **Hover Transitions**: All cards and buttons include subtle `transition: all 0.3s ease` for smoothness.
- **Scroll Reveal**: An `animate-fade-in` utility is available for page transitions and section reveals.

### Navigation Logic
Navigation is centralized in `src/lib/config.ts`. The **Header** component dynamically renders these items and manages:
- **Scroll State**: Switches to a sticky glass background when the user scrolls down.
- **Active States**: Highlights the current route for user orientation.

## 📝 Maintenance & Updates
To update the project:
1. **Change Colors**: Modify variables in `src/app/globals.css`.
2. **Add Navigation**: Add an entry to `SITE_CONFIG.navItems` in `src/lib/config.ts`.
3. **Change Icons**: Import and use any icon from the `lucide-react` library.
